# Changelog

All notable changes to this package are documented in this file.

## [0.1.1] - 2026-11-27

### Added

- Assets-installable `.unitypackage` release. Importing it places the package under `Assets/57Studios/TerrainScatter`.

## [0.1.0] - 2026-11-26

### Changed

- Relicensed under MIT for public distribution.

### Added

- Initial UPM package migration from the 57 Studios TestBench project.
- Terrain-layer-aware prefab scattering with slope, spacing, scale, rotation, and seed controls.
- Undoable scatter and clear operations.
- EditMode tests for the generator.
- Package README, license, and package manifest.
